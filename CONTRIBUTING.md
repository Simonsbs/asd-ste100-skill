# Contributing

Open an issue or pull request with the behavior to improve and the relevant
official source, edition, page, and rule number. Distinguish a normative requirement
from a project convention or an unresolved interpretation.

Keep contributions small enough to review. Use original explanations and examples.
Link to protected publications instead of copying them. Do not add standards,
dictionary datasets, third-party course materials, confidential input text, or
claims that a tool is endorsed or certified by ASD.

Run `python scripts/validate_project.py` and
`python -m unittest discover -s tests -v`. New executable helpers need a meaningful
behavioral check. For source updates, follow [the maintenance procedure](docs/MAINTENANCE.md).

MIT licensing of a contribution covers only material you have the right to license.
No contributor agreement or external account is needed to run the skill locally.
